# My Foundry Studies ⚒️

This repository documents my hands-on journey learning **Foundry** for Ethereum and Solidity smart-contract development.

I started my Solidity journey primarily through **Remix**, where I focused on understanding the language and experimenting with individual contracts.

As my studies progressed, I began moving toward a more complete development workflow with **Foundry** — learning how smart contracts are compiled, tested, scripted, deployed, and interacted with from the command line.

This repository is where I will document that transition.

---

## 🎯 Purpose

The goal of this repository is not simply to collect working Solidity code.

It is a record of **what I learn, how I understand it, and how my development workflow evolves**.

The studies here focus on understanding the tools and concepts behind professional smart-contract development, including:

- Solidity development with Foundry
- Project structure and configuration
- Compilation
- Testing
- Deployment scripts
- Local blockchain development
- RPC endpoints
- Transaction broadcasting
- Contract interaction
- Foundry cheatcodes
- Smart-contract debugging
- Chainlink integrations
- Ethereum development workflows
- And eventually more advanced Web3 concepts

As I progress, this repository will grow with me.
